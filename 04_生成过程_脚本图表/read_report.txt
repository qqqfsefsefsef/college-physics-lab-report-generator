【六】常数偏移 6 的核对 —— 确认不影响斜率
  学生算 lg(T²) 时把 T 代成了 T/10^3 K：
    lg(T²)|用 T/10^3  = 2lg(T/10^3) = (2lgT) - 6 = lg(T²)|真实 - 6
  故  第4行 = lgI - 2lg(T/10^3) = lg(I_s/T²)|真实 + 6 。
  逐点核对 第3行 - 第4行 (实测) = 0.54  0.56  0.58  0.59  0.61  0.63  0.66  0.67
           2lg(T/10^3)   (计算) = 0.548  0.567  0.585  0.602  0.619  0.636  0.653  0.669
  → 两行逐点相符，最大偏差 0.012（学生只保留两位小数所致）；平均值 0.6050。
  2lgT      = 6.548  6.567  6.585  6.602  6.619  6.636  6.653  6.669
  2lg(T/1e3)= 0.548  0.567  0.585  0.602  0.619  0.636  0.653  0.669
  2lgT - 2lg(T/1e3) 恒等于 2lg(1000) = 6.000（8 点全部成立）。
  也就是说：第 4 行比真实的 lg(I_s/T²) 处处高 6.000，等价于学生把 lg(T²) 写成了
  lg((T/10^3)²)，漏掉了 10^3 的平方因子；这是一个只平移、不改变形状的常数偏移。
  最小二乘斜率 = Σ(x-x̄)(y-ȳ)/Σ(x-x̄)²，y 整体平移常数时
  ȳ 同步平移、y-ȳ 不变，因此斜率完全不变：
    用原始第 4 行    拟合斜率 = -22.095238
    用第 4 行 - 6.0  拟合斜率 = -22.095238
    两者之差 = 3.55e-15  → 平移 6 不影响 eφ，只让截距 b 差 6.0。

【九】逸出功
  m_true = m × 10^3 = -22095.2381  K^-1
  eφ = 2.303 · k · |m_true| ，k = 1.3806505e-23 J/K ，e = 1.602e-19 C
     = 2.303 × 1.3806505e-23 × 22095.2381
     = 7.025486e-19 J
     = 7.025486e-19 J / 1.602000e-19 C = 4.3854 eV
  公认值 eφ = 4.54 eV
  绝对误差 = -0.1546 eV
  相对误差 E = (4.3854 - 4.54) / 4.54 = -3.404 %

【十】稳健性变体
  A. 横坐标改用未截断的 1/(T·10^3)：斜率 = -22.4770，b = 12.7227，r^2 = 0.999456
     -> eφ = 4.4612 eV
  B. 纵坐标改用本次由表 2 外推的 lg I_s 重算（lg(I_s/T^2) 真实值）：
     斜率 = -22.6910，b = 6.8136，r^2 = 0.996985
     -> eφ = 4.5037 eV
  结论：三种做法的 eφ 依次为 4.3854 / 4.4612 / 4.5037 eV，
        相对误差依次为 -3.40% / -1.74% / -0.80%，全部落在 -3.4% ~ -0.8%，
        即横坐标若坚持用学生截断的 0.53/0.52/… ，偏差最大（约 3.4%）；
        判读取整带来的差异不足以改变“eφ 略低于公认值 4.54 eV”这一结论。

  6) 表2 / T=1.88 整行 与 T=2.12 行 U_a=144 格
