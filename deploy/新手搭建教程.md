## 1. 先认 8 个词（30 秒，不懂也能照着做）

| 词 | 一句话 |
|---|---|
| **服务器 / VPS** | 一台放在机房、永远开机的电脑，你租它 |
| **IP 地址** | 这台电脑的门牌号，像 `123.45.67.89` |
| **SSH** | 用命令行远程操作这台电脑（Windows 自带，不用装软件） |
| **端口** | 门牌号后面的房间号。网站用 **80**（http）和 **443**（https） |
| **安全组 / 防火墙** | 云厂商的「门禁」，**默认关着 80/443，必须手动放行** |
| **域名** | 好记的名字，如 `report.abc.com`，要花钱买（几十元/年） |
| **解析 / A 记录** | 把域名指向服务器 IP 的那条设置 |
| **备案** | 国内服务器用域名访问网站，必须向工信部登记；香港/海外免 |

## 2. 路线甲：不买服务器，10 分钟上线（¥0）

**原理**：你的电脑跑服务，Cloudflare 给你一个公网 https 地址，别人访问那个地址就等于访问你的电脑。

### 2.1 装一次 cloudflared（只装一次）

开始菜单搜 **PowerShell** → 右键「以管理员身份运行」→ 粘贴：

```powershell
winget install --id Cloudflare.cloudflared
```

出现 `已成功安装` 就好。**关掉这个窗口，重开一个 PowerShell**（不然它找不到新命令）。

### 2.2 启动

```powershell
cd "C:\Users\lidey\Desktop\实验报告制作沙盒\06_网站方案"
.\start.cmd -Tunnel
```

屏幕上会打出两行 `https://xxxx-xxxx.trycloudflare.com`：

- 第一行通常是**页面地址** → 复制发给同学
- 第二行是**识别桥地址** → 同学打开页面后，点右上角「连接设置」，把它填进去

> 首次启动 Windows 会弹「防火墙」提示，勾**专用网络**点允许。

### 2.3 什么时候该升级到路线乙

- 你的电脑一关，别人就打不开
- 每次重启地址都会变，得重新发一遍
- 家里上传带宽小，传 4000×3000 的手机照片会慢

## 3. 路线乙：买一台香港轻量服务器（推荐，24 元/月起）

### 3.1 买之前准备

1. 一个手机号 + 支付宝/微信（要实名，**学生用身份证就行**）
2. 你的电脑（Windows，用自带 PowerShell 连服务器）

### 3.2 下单（以腾讯云/阿里云为例，两家界面大同小异）

1. 打开 [腾讯云轻量应用服务器](https://cloud.tencent.com/product/lighthouse) 或 [阿里云轻量应用服务器](https://www.aliyun.com/product/swas)
2. 地域选 **中国香港**（免备案）；配置选 **1 核 1G 或 1 核 2G**、**系统镜像 Ubuntu 22.04 / 24.04**、带宽 30M、流量 1T
3. 时长选 **1 个月**先试（别一上来买三年）
4. 付款后在控制台 →「实例」里能看到：
   - **公网 IP**（记下来，例如 `43.xx.xx.xx`）
   - **用户名**：`root`（Ubuntu 镜像一般是 root，或 ubuntu）
   - **密码**：下单时设的，或点「重置密码」重设一个（**记牢**）

### 3.3 放行 80 / 443（不做这步，网站一定打不开）

控制台 → 你的服务器 → **防火墙 / 安全组** → 添加规则：

| 协议 | 端口 | 来源 | 备注 |
|---|---|---|---|
| TCP | 80 | 0.0.0.0/0 | http |
| TCP | 443 | 0.0.0.0/0 | https |

> 只要 80/443，**不要**把 8732 开放到公网（识别桥只给本机反代用）。

### 3.4 连上服务器

Windows 开始菜单搜 **PowerShell**，打开后输入（把 IP 换成你的）：

```powershell
ssh root@43.xx.xx.xx
```

第一次会问 `Are you sure you want to continue connecting?` → 输入 `yes` 回车 → 再输密码（**输入时屏幕不显示，正常，输完回车**）。

看到类似 `root@VM-0-2-ubuntu:~#` 就成功了。**从这里开始，所有命令都在这个黑窗口里敲。**

### 3.5 装 Docker（一条命令，2 分钟）

```bash
curl -fsSL https://get.docker.com | sh
docker -v          # 能打印版本号就成功
```

### 3.6 把部署包传上去

**先在你的 Windows 电脑**（另开一个 PowerShell 窗口，**不要**在 ssh 那个窗口里）执行：

```powershell
cd "C:\Users\lidey\Desktop\实验报告制作沙盒"
ssh root@43.xx.xx.xx "mkdir -p /opt/report"
scp -r .\deploy\server\* root@43.xx.xx.xx:/opt/report/
```

- 会问密码，输一次
- 看到一行行文件名滚过去就对了，大约 4 MB，很快

> `scp` 是 Windows 自带的，不用装任何东西。
> 如果提示 `scp 不是内部或外部命令`：说明是很老的系统，改用 `tar` + `ssh`，或者装个 WinSCP 图形界面拖拽上传。

### 3.7 配置（只改一行）

回到 **ssh 那个窗口**：

```bash
cd /opt/report
cp .env.example .env
nano .env
```

**nano 怎么用**：方向键移动光标，改完按 `Ctrl+O` 再回车（保存），按 `Ctrl+X` 退出。

只有一行必须改：

```ini
SITE_ADDR=:80          # 先用 IP 访问，就保持这样
# SITE_ADDR=report.abc.com   # 有了域名再改成这个（见 §3.10）
```

### 3.8 启动

```bash
docker compose up -d --build
```

第一次会拉镜像（python + caddy，约 2–3 分钟）。看到 `Started` 就好。

### 3.9 验收

```bash
curl -s http://127.0.0.1:8732/health
```

应该返回一大段 JSON，里面有 `"ok":true`、`"experiments":[11 个]`。

浏览器打开 `http://43.xx.xx.xx/`：
1. 出现公告 → 点「我已知晓」
2. 上传一张原始数据记录页照片 → 稍等，自动认出实验名
3. 核对页会一道一道问你「这一格是不是这个数」
4. 点「数字都对，生成报告」→ 下载 docx

**如果打不开**：99% 是 §3.3 的端口没放行，或者 `docker compose ps` 里服务不是 running。

### 3.10 想用域名（可选，但更像样子）

1. 买域名：阿里云/腾讯云/Namecheap 都行，`.top`/`.xyz` 一年十几元
2. 进域名控制台 → **解析** → 添加记录：
   - 记录类型 `A`，主机记录 `report`（或 `@` 表示根域名），记录值 = 你的服务器 IP
3. 等 5–10 分钟，本机 `ping report.你的域名` 能显示出你的 IP 就生效了
4. 服务器上改 `.env`：

```bash
cd /opt/report && nano .env      # SITE_ADDR=report.你的域名
docker compose restart web
docker compose logs --tail=30 web | grep -i -E "certificate|error"
```

5. 浏览器打开 `https://report.你的域名` —— Caddy 会自动申请免费证书（约 30 秒），地址栏出现小锁 🔒

> ⚠️ **香港/海外服务器不需要备案**；如果换成国内地域的服务器，用域名访问必须备案，否则会被拦。

## 4. 路线丙：一定要国内服务器（要备案）

1. 按 §3.2 买**国内地域**（如广州/上海）的轻量服务器
2. 买域名 → 在云厂商提交 **ICP 备案**（手机拍身份证、人脸核验，1–3 周，期间网站不能用 80/443 域名访问，但 `http://IP` 一般可以先用）
3. 备案通过后按 §3.10 配域名
4. 备案号要放到网站底部（法规要求）

**建议**：除非你确定长期做，否则先走路线乙，省掉备案 2–4 周的等待。

## 6. 新手 12 个坑（症状 → 原因 → 处理）

| 症状 | 原因 | 处理 |
|---|---|---|
| 浏览器转圈最后「连接超时」 | 80/443 没放行，或服务没起 | 控制台放行端口；`docker compose ps` 看是否 running |
| `ssh: connect to host ... timed out` | IP 写错 / 服务器没开机 / 22 端口没放行 | 控制台看实例状态；放行 22 |
| 输密码一直提示错误 | 复制时带了空格；或用户是 `ubuntu` 不是 `root` | 手动输入；试 `ssh ubuntu@IP` |
| `docker: command not found` | Docker 没装成功 | 重跑 §3.5 那条命令；国内机器慢可换阿里云镜像源 |
| `docker compose` 报错找不到命令 | 老版本是 `docker-compose` | 用带空格的 `docker compose`；或 `apt install docker-compose-plugin` |
| 页面打不开但 `/health` 正常 | Caddy 没起来 | `docker compose logs web` |
| 页面能开，点生成报「502」 | bridge 挂了 | `docker compose logs bridge`，看有没有报错 |
| 识别报「还没有密钥」 | 没填 key | 页面首页填自己的 key（只在内存），或在 `.env` 配 `DEEPSEEK_API_KEY` |
| 识别报「模型没有返回 JSON」 | 思考模式吃光 token（已修） | 确认用的是我给的包；看日志里的 `finish_reason` |
| 上传 HEIC 报错 | 镜像里没装 pillow-heif | 我给的 Dockerfile 已装；裸机则 `pip install pillow-heif` |
| 域名小锁不出来 | 域名没解析对 / 用了 IP | `ping 域名` 看是不是你服务器 IP；DNS 生效要等 |
| 磁盘满了 | 生成物堆积 | `du -sh /opt/report/data/*`；`.env` 里调小 `PROJECT_KEEP_DAYS` |

## 7. 安全底线（4 条，别省）

1. **`.env` 里有密钥，绝不外发、不要提交到 GitHub**。
2. 如果要「你替所有人付钱」，务必同时设 `BRIDGE_TOKEN`（一串随机的字），只发给同学；不然别人拿到地址就能刷你的额度。
3. **不要**把 8732 端口开放到公网（只在服务器内部反代）。
4. 长期用建议：SSH 改成密钥登录、禁用密码登录（新手可等稳定后再做）。
