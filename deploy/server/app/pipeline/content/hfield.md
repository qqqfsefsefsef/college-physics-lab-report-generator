=== 原理1 ===

霍尔效应是导电材料中的电流与磁场相互作用而产生电势差的现象。1879 年美国物理学家霍尔在研究金属箔片的导电性质时发现了这一效应：把通有电流的导体放在与电流方向垂直的磁场中，在与电流和磁场都垂直的方向上会出现一个稳定的电势差，人们后来把这一现象称为霍尔效应。金属中的载流子是自由电子，电子数密度很大，霍尔电压很小，所以这一效应最初很难投入实际应用。

半导体材料的载流子浓度比金属低得多，用半导体薄片做成的霍尔元件在同样的电流和磁场下能产生大得多的霍尔电压，通常可达毫伏量级，因而被广泛用于磁场测量、非电量测量、自动控制和计算装置等方面。近年来霍尔效应还在凝聚态物理中得到深入研究，并在低温和强磁场条件下表现出量子化的特征。

从微观上看，导体中做定向运动的载流子在磁场中受到洛伦兹力 F = qvB 的作用，运动方向发生偏转，从而在垂直于电流和磁场的两个侧面之间出现电荷积累，形成附加的横向电场。当电场力与洛伦兹力平衡时，载流子不再发生横向漂移，两侧之间就维持一个稳定的电势差，这就是霍尔电压。对于给定的霍尔元件，霍尔电压与工作电流及磁场垂直于元件平面的分量成正比。

由载流子受洛伦兹力偏转的模型还可以判断载流子的导电类型：若霍尔电压的符号与按电子模型算出的相反，就说明载流子是带正电的空穴。霍尔电压与电流、磁场的乘积成正比，只与材料性质和几何尺寸有关，因此霍尔元件既可用来测量磁场，也可用来判别半导体材料的类型、测量载流子浓度和迁移率。

当两线圈的间距不等于半径时，轴线上的分布会明显改变：间距过小时中点磁场虽然更强，但均匀区变窄；间距过大时中点附近甚至会出现凹陷。因此实验中必须把两线圈的间距调到等于半径，并用定位装置保证两线圈严格共轴、线圈平面互相平行，否则中点磁场会偏离理论值。从两线圈磁场的叠加还可以看出，中间区域的均匀程度由两线圈的间距与半径之比决定，等于半径只是其中最优的一种选择；间距稍有偏差，均匀区的范围和中心磁场都会随之改变。

测量中除霍尔电压外，还混有埃廷斯豪森效应、能斯特效应、里吉—勒杜克效应和不等势电位等副效应。实验采用对称测量法：在同一位置分别取（+I_s，+I_M）、（+I_s，−I_M）、（−I_s，−I_M）、（−I_s，+I_M）四种状态，记下四组读数 V1~V4，再取 V_H = (V1 − V2 + V3 − V4)/4。这样能斯特效应、里吉—勒杜克效应和不等势电位在求和中相互抵消，只剩方向与霍尔电压相同的埃廷斯豪森效应，因其量级很小可以忽略。

磁场满足叠加原理：两线圈同时通电时空间任一点的磁感应强度等于两线圈单独通电时在该点产生的磁感应强度的矢量和。由于轴线上的磁场方向都沿轴线，可以把两个标量直接相加。本实验分别测出线圈 1、线圈 2 单独通电时的磁场，把对应点的数值相加，再与两线圈同时通电时的测量值比较，即可验证叠加原理。

=== 仪器 ===

本实验使用三维亥姆霍兹线圈磁场实验仪及其测试架。实验仪面板上装有励磁电流表、霍尔工作电流表和霍尔电压毫伏表，并配有相应的调节旋钮，可以分别提供励磁电流和霍尔工作电流，并把霍尔电压直接显示出来，读数比较方便。

测试架上装有两个圆线圈，其中一个固定，另一个可以沿导轨移动，以便把两线圈的间距调到所需的数值；线圈后面有接线插孔，可以接成单个线圈，也可以把两个线圈同向串联。霍尔元件装在铜管前端，铜管由三维移动装置带动，可以沿 X、Y、Z 三个方向移动，各方向都配有位置标尺，用来读取元件的位置。实验时还要用连接导线把实验仪与测试架上的对应端子一一接好。

=== 步骤 ===

一、接线与预热。按面板上的标识把励磁电流、霍尔工作电流和霍尔电压三对端子与测试架上的对应端子连接，注意红黑两色对应，不要接错。开机前把两个电流调节旋钮都逆时针旋到底，使输出电流处于最小状态，然后接通电源，预热约 10 分钟，待显示稳定后再开始测量。

二、调整几何位置。把两线圈的间距调到等于线圈半径，并把铜管位置也调到相应位置，使两线圈的中点位于移动装置的坐标原点；把 Y、Z 两个方向的滑块都调到零位并锁紧，保证霍尔元件位于线圈轴线上。移动滑块时用力要轻，不能沿前后方向用力，以免改变已经调好的位置。

三、调零。把霍尔电压输入端短接，或把工作电流和励磁电流都调到零，再调节面板上的调零旋钮，使毫伏表显示为零。调好后松开短接线，此后测量中不再动调零旋钮。

四、测量线圈 1 的磁场。把励磁电流接到线圈 1，调节工作电流和励磁电流到规定值，从 x = −120 mm 开始，每移动 10 mm 记录一组数据：依次改变工作电流和励磁电流的方向，读出四种换向状态下的霍尔电压 V1~V4。移动后应稍等片刻，待读数稳定再记录。

五、测量线圈 2 的磁场。把励磁电流改接到线圈 2，保持工作电流和励磁电流不变，重复上述逐点测量，把数据记入表 2。

六、测量两线圈同时通电的磁场。把两线圈按同向串联接好，接到励磁电流输出端，重复沿轴线逐点测量，记入表 3；同时注意记录 x = 0 处的读数，用于标定霍尔灵敏度。

七、数据处理。按对称测量法算出各点的霍尔电压，由中心点读数标定灵敏度，再逐点换算磁感应强度，作出磁场沿轴线的分布曲线，比较单线圈与两线圈的结果，并检验磁场叠加原理。

=== 数据说明 ===

表 1 至表 3 分别记录线圈 1、线圈 2 单独通电和两线圈同向串联时轴线上的数据。每一行给出位置 x 和四种换向状态下的霍尔电压 V1~V4，霍尔电压 V_H 与磁感应强度 B 两列由对称测量法和标定结果算出，列在表中便于逐步检查。

处理时先算每点的霍尔电压 V_H = (V1 − V2 + V3 − V4)/4，再取表 3 中 x = 0 处的读数 V_H0，按 K_H = V_H0/(I_s·B0) 标定灵敏度，其中 B0 取两线圈中心磁场的理论值 2.25 mT。然后由 B = V_H/(K_H·I_s) 逐点换算磁感应强度。

为了检验单线圈的结果，可把每个线圈中心处的实测值与 μ0NI/(2R) 比较；为了检验叠加原理，把表 1 与表 2 同一位置的 B 相加，再与表 3 的数值逐点比较，求出相对偏差。还可以以 B(1) + B(2) 为横轴、B(R) 为纵轴作直线，若斜率接近 1、相关系数接近 1，就说明两线圈磁场的叠加是线性叠加。

最后结合理论曲线讨论分布规律：单线圈磁场在中心处最大，两侧迅速减小；双线圈在中心附近有一段较平坦的区域，离开均匀区后才明显下降。处理中间结果时多保留一两位，最终结果按有效数字规则表示。

=== 体会 ===

刚看到实验题目时，我以为霍尔效应只是把探头放进磁场、读一个电压那么简单，真正动手才发现，要得到可信的磁场数值，前面的准备工作比读数本身更重要。接线时我要对照面板和测试架上的标识一根一根地核对，红黑端子不能接反；开机前还必须把两个电流旋钮都退到零，否则冲击电流可能损坏霍尔片。这些细节在讲稿上只有一句话，做的时候却要格外小心。

调零和换向读数是最花时间的一步。同一个位置要分别改变工作电流和励磁电流的方向，一共读出四组数，每换一次方向读数都会变一点，有的甚至变号。起初我图快，换向之后马上读数，结果同一组数据前后对不上；后来我改成换向之后等几秒、看显示稳定了再记，数据才顺下来。这时我才真正理解讲稿里为什么要用对称测量法：不是把简单问题复杂化，而是用四次测量把那些消不掉的副效应抵消掉。

移动铜管的位置也很考验耐心。移动装置的导轨有一点间隙，推的时候如果用力不均，元件就会偏离轴线，读数随之出现不规律的起伏。我后来养成了每次移动后先看位置标尺、再轻敲一下确认读数稳定的习惯，并且沿同一方向逐点移动、不来回乱推。这样测出来的曲线才平滑对称，和理论上单线圈磁场的分布形状对得上。

处理数据时，中心点读数与理论值的偏差让我有点意外：两线圈中心的磁场并不是两个单线圈中心磁场的简单平均，而是略大一些，这正是两线圈磁场叠加的结果。我又用单线圈中心磁场的理论公式核对，发现差别主要来自灵敏度的标定，而灵敏度又是由中心点那一个读数定出来的，所以中心点的读数必须特别可靠。这一点让我意识到，实验中最关键的数据往往不是最多的那批，而是给整个计算定基准的那一个。

通过这次实验，我对“把微小效应放大再测量”和“用对称的测量消除系统误差”这两种思想有了具体的体会。前者体现在霍尔元件用半导体薄片做成、让几毫伏的电压变得容易读出；后者体现在四种换向状态的设计上。我也体会到，实验数据不能看到数字就照抄，要随时用理论曲线和相邻点的趋势去检查，发现异常先找原因再决定是否重测。

=== 思考题 ===

1. 如何用霍尔效应法测量地磁场？

（答）地磁场很弱，直接测量时霍尔电压只有微伏量级，应选用灵敏度高、薄片较薄的霍尔元件，并适当加大工作电流。测量时把元件水平放置，让其法线分别指向几个不同的方位，用换向法测出各方向的霍尔电压；再绕竖直轴缓慢转动元件，读数最大的方向就是地磁场水平分量的方向。用已知磁场标定灵敏度后，即可由霍尔电压换算出地磁场的大小。

2. 通电亥姆霍兹线圈周围磁场呈什么分布？

（答）单个通电圆线圈的磁场在圆心处最强，沿轴线向两侧按 (R² + x²)^(−3/2) 的规律减小。两个同向串联、间距等于半径的线圈组成亥姆霍兹线圈，轴线中点附近磁场叠加后比较平坦，形成一个较宽的均匀区，中点磁场约为单线圈中心的 1.43 倍；离开均匀区后磁场逐渐减弱，两端各自呈现单个线圈的峰形分布。

3. 为什么测量时要改变工作电流和励磁电流的方向？

（答）因为测量中除霍尔电压外还混有埃廷斯豪森效应、能斯特效应、里吉—勒杜克效应和不等势电位等副效应，这些附加电压随工作电流或励磁电流反向而改变符号。把两种电流分别换向得到四组读数，再按 (V1 − V2 + V3 − V4)/4 取平均，副效应在求和中相互抵消，就能得到比较纯净的霍尔电压，从而减小系统误差。

4. 若霍尔元件平面与磁场方向不垂直，测量结果会怎样？

（答）霍尔电压与磁场垂直于元件平面的分量成正比，即 V_H = K_H·I_s·B·cosθ。若元件平面与磁场方向不垂直，测得的只是磁场的法向分量，读数偏小，按 B = V_H/(K_H·I_s) 换算会把磁场算小。判断方法：绕元件法线缓慢转动元件，读数最大的方向就是元件平面与磁场垂直的方向。
