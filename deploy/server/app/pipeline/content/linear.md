=== 原理1 ===

一般物体都具有热胀冷缩的性质。固体受热时，内部相邻分子之间的平均距离随温度升高而增大，宏观上表现为物体各个方向的线度都变大，这种现象叫做热膨胀。固体的体积随温度升高而增大的现象称为体膨胀，而把固体受热后某一个方向上的长度增长称为线膨胀。对大多数各向同性的固体来说，各个方向上的线膨胀规律相同，因此可以用一个方向上的线膨胀来表征它的热膨胀特性，描述这种特性的物理量就是线膨胀系数。线膨胀系数是材料的重要技术指标：道路与桥梁要留伸缩缝，精密仪器的零件要避免因温度变化而卡死，异种材料的焊接要考虑膨胀量是否匹配，这些工程问题都要用到它。

实验表明，固体受热后的长度 L 与温度 t 之间的关系可以写成温度的多项式，式中 L_0 是温度 t = 0 ℃ 时的长度，α、β 等是与材料有关的很小的常数。由于 β 及其后的系数与 α 相比极小，常温下把二次以上的项全部略去，就得到线性关系式。这个近似在温度变化不大的范围内与实际符合得很好，也是本实验能够用一个常数描述热膨胀的前提。

F1  L = L₀(1 + αt + βt² + …)

F2  L = L₀(1 + αt)

式中的 α 就是固体的线膨胀系数，它的物理意义是温度每升高 1 ℃ 时，物体的伸长量与它在 0 ℃ 时的长度之比，单位是摄氏度分之一。不同材料的线膨胀系数相差很大：塑料的最大，金属次之，大多数金属的线膨胀系数在 10⁻⁵ ℃⁻¹ 的量级。正因为 α 是一个与材料有关、与试样尺寸无关的常数，它才能作为表征材料热学性质的参数；也正因为它的数值很小，测量时必须把微小的伸长量放大到可以准确读出的程度。

=== 原理2 ===

按照式(2)，只要知道 0 ℃ 时的长度 L_0 和某一温度下的长度 L，就能算出 α。可实际测量时并没有办法把金属棒冷却到 0 ℃ 再测长度，L_0 本身无法直接得到。解决的办法是改测两个不同温度下的长度：设温度为 t_1 时棒长为 L_1，温度为 t_2 时棒长为 L_2，把它们分别代入式(2)，就得到两个方程。这两个方程里的 L_0 是同一个未知量，把它消去，α 就可以完全由两次测量的长度和温度表示出来。

联立这两个方程可得 α 的表达式，式中分母里出现 L_2/L_1 这一项。由于金属的线膨胀系数很小，在几十摄氏度的温度范围内 L_2 与 L_1 只相差万分之几，L_2/L_1 与 1 的差别完全落在测量误差之内，可以近似取为 1。于是表达式简化为 ΔL 与 L_1、Δt 的关系，再把 L_1 换成棒的原长 L，就得到实验中最常用的形式。

F3  α = (L₂ − L₁)/[L₁(t₂ − (L₂/L₁)t₁)]

F4  α = ΔL/(L₁Δt)

F5  α = ΔL/(LΔt)

式中 L 为物体的原长，ΔL = L_2 − L_1 是温度变化 Δt = t_2 − t_1 时对应的伸长量。这个式子说明：线膨胀系数等于单位温度变化引起的相对伸长量，它把测量 α 的问题化成了测量一个温度差和一个长度差的问题。

需要说明的是，线膨胀系数本身也随温度略有变化。当 Δt 很小时，由式(5)算出的 α 称为固体在该温度处的微分线膨胀系数；当 Δt 是一个不太大的区间时，近似认为区间内 α 不变，算出的则是该温度区间内的平均线膨胀系数。本实验测得的是后者。由式(5)还可以看出，在 L 已知的情况下，测量 α 的关键归结为准确测量 Δt 和 ΔL；由于 α 的数值很小，ΔL 也极小，测量的相对误差很容易被放大，所以如何准确地控制和测量温度、如何把微小伸长量测准，就成了本实验成败的关键。

=== 原理3 ===

伸长量的测量是本实验最困难的一步。一根半米长的金属棒，温度升高十几摄氏度，伸长量也只有零点一毫米的量级，用米尺根本读不出来。实验用千分表来测这段位移：千分表内部是齿条与齿轮传动机构，测杆的直线位移经齿条带动齿轮，转换成表针的角位移，大表针转过一圈代表测杆移动 0.2 mm，表盘最小分度值为 0.001 mm。把千分表的测杆顶在金属棒的滑动端上，棒的伸长就推动测杆，表针随之转动，微小的长度变化被转换成可以估读到零点几微米的角度变化。这正是本实验把微小伸长量「放大」的手段。

温度的控制同样重要。金属棒装在一根空心管内，恒温水从进水孔流入、从出水孔流出，把棒整体浸泡在循环水中加热。水浴的好处是棒的温度均匀，而且水温由温控仪闭环控制，比用酒精灯或电炉直接加热稳定得多。当水温达到设定值并且波动小于 0.1 ℃、持续两分钟不变时，才认为棒与水已经充分交换热量、达到热平衡，这时记录的温度才能代表棒的温度。实验中每隔 3 ℃ 左右设一个温度台阶，共测六组，第一组既作为温度基准 t_1，也作为千分表读数的基准 l_1。

以第一组为基准做差，除了省去 L_0 之外，还有一个好处：千分表的零点、测杆与棒端接触时的初始压紧量、棒在装夹时的初始应力，都在相减时一并消掉了，剩下的只是纯粹的伸长量。金属棒做得比较长，是为了让同样温升下的伸长量大一些，读数相对误差小一些；但温度台阶又不能太大，否则金属棒与水温的滞后、支架的热膨胀都会掺进来。仪器支架用隔热材料制作，正是为了减小支架自身受热膨胀带来的系统误差，因为千分表测量的位移里包含了支架的变形，支架与棒的热膨胀不一致时，读数就会偏离棒的真实伸长。

=== 原理4 ===

温度能够稳定在设定值附近，靠的是自动控制。把温控系统画成框图：给定一个设定温度，它与被控对象的实际温度（被控量）相比较，得到偏差 e(t)；调节器按某种规律由偏差算出调节信号 u(t)；执行单元把这个信号变成加热功率，作用于水箱中的水；水温又被温度传感器测出并反馈回去，构成闭环。加热过程中外界散热、水温分布不均、环境温度变化都可以看成加在系统上的扰动，闭环的作用就是让被控量在扰动下仍能回到设定值。

本实验的温控仪采用 PID 调节规律，调节信号由偏差的比例项、积分项和微分项相加而成。比例项与偏差成正比，偏差一出现就立刻给出调节量，反应快，但单靠比例调节总会留下一个稳态偏差；积分项与偏差对时间的积分成正比，只要还有偏差就继续累积，直到偏差被完全消除，因此它能消除静态误差，但作用太强会使系统超调、甚至振荡；微分项与偏差的变化率成正比，它「预判」温度的变化趋势，在温度快要接近设定值时提前减小加热功率，从而抑制超调、缩短调节时间。

F7  u(t) = K_p[e(t) + (1/T_i)∫e(t)dt + T_d·de(t)/dt]

从过渡过程曲线可以读出几个指标：系统第一次超过设定值的部分叫超调，超调的最大偏离量称为动态偏差，稳定后残留的偏差称为静态偏差，从扰动开始到进入允许误差带所需的时间称为过渡时间。稳定性、准确性和快速性三者互相制约，参数要折中整定。本仪器的 PID 参数是厂家在理论上分析、在大量实验上整定好的，不开放调节，这对实验来说是好事：控温的重复性好，测得的每一个 t_i 才具有可比性。因为 Δt 只有十几摄氏度，温度若有 0.1 ℃ 的偏差，相对误差就到百分之一量级，所以控温精度直接决定了线膨胀系数的不确定度。

=== 仪器 ===

金属线膨胀实验仪是主体装置，由基座、固定端支架、滑动端支架、空心金属棒、进出水孔和千分表支架组成。金属棒一端用螺钉连接在固定端支架上，另一端由滑动端支架上的轴承支承，可以在长度方向上自由伸缩；千分表的测杆顶在棒的滑动端，棒受热伸长时推动测杆。支架用隔热材料制作，减小支架自身受热膨胀对读数的影响。

温控实验仪由水箱、水泵、加热器、控制及显示电路组成，面板上有水位上下限指示、启控/停控键、方向键、确认键、返回键和电源开关。仪器内置微处理器，用液晶菜单设置序号、室温和设定温度，能实时显示温度与加热功率，并按固定间隔采样、绘出温度曲线，一次实验的曲线可以按序号存储下来，便于事后比较。

千分表是精密位移量具，靠齿条—齿轮传动把测杆的直线位移转换为表针的角位移，大表针转一圈（小表针转一格）代表 0.2 mm 的线位移，最小分度值为 0.001 mm。读数时要估读到分度值的十分之一，并且轻拿轻放，不能用力挤压测杆。

=== 步骤 ===

先检查水位。通电前水位必须高于水位下限，若低于下限，要从顶部注水孔用漏斗补水，水位过低时水泵会空转并发出鸣响，既测不准也容易损坏水泵。确认水位正常后再接通电源，开机后水泵启动，出水口的软管应有轻微颤动，说明水循环已经建立。

接着装夹试件。把金属棒装到固定端支架和滑动端支架上，调整千分表支架的高度与方向，使测杆垂直接触棒的滑动端并有一定压紧量，表针有合适的初始读数，但不要压得太紧。装好后先升温观察一次，确认千分表读数随温度单调增大、没有卡滞或跳变，然后再开始正式测量；一旦开始升温读数，就不要再触动实验仪。

设定测量参数。在温控仪的菜单里选择进行实验，输入序号、室温与第一个设定温度，用方向键修改数值并确认，按启控键开始升温。测量界面会显示设定温度、初始温度、当前温度、当前功率和调节时间，图形区以时间为横轴、以温度（或功率）为纵轴实时绘制曲线，仪器按固定时间间隔采集一次数据。

等温度平衡后读数。当显示温度达到设定值、并保持两分钟波动小于 0.1 ℃ 时，仪器自动判定平衡，同时给出过渡时间、动态偏差和静态偏差。此时记下当前温度 t_i 和千分表读数 l_i，然后按停控键停止，把设定温度提高一个台阶再启控，重复上述过程，直到测完六组。

关机后处理数据。先停控、再关电源，等水温降下来再拆表和放水。数据以第一次的 (t_1, l_1) 为基准算出 Δt_i 与 ΔL_i，以 Δt 为横轴、ΔL 为纵轴作图或作最小二乘拟合，求出直线斜率 K，再由 α = K/L_1 算出线膨胀系数，最后按 A 类与 B 类分量合成不确定度并写出结果。

表 1 是按讲稿的表头抄录的原始记录表，行是各物理量、列是测量次数，第一次既作为温度基准又作为读数基准，所以它的 Δt 与 ΔL 按定义都为零，表中首列画短横线表示不再重复记录。录入数据时只填设定温度、实测温度和千分表读数三行，Δt 与 ΔL 两行是由这三行算出的，复核时应先核对这两行与原始记录是否一致。

作图的横轴取 Δt、纵轴取 ΔL，单位分别用摄氏度和微米，纵轴这样取是因为伸长量只有零点几毫米，换算成微米后数值在百的量级，作图时点与点之间的差别看得清楚。除第一次的原点外，各点应当分布在一条直线附近；用直尺拟合时让点均匀分布在直线两侧，求出的斜率 K 的单位是微米每摄氏度。

由 K 求 α 时要注意单位：α = K/L，K 要用毫米每摄氏度，所以先把以微米每摄氏度给出的 K 乘以 10⁻³，再除以以毫米为单位的原长，得到的 α 单位就是每摄氏度。这一步很容易漏乘或错乘 10⁻³，可以在结果量级上核对：金属的 α 应当在 10⁻⁵ ℃⁻¹ 的量级，若算出来是 10⁻² 或 10⁻⁸，一定是单位换算错了。

不确定度分两部分：A 类来自拟合斜率本身的标准偏差，由各点偏离直线的程度算出；B 类来自仪器，千分表的示值误差、温控仪的温度分辨力、原长给出的误差限，都按均匀分布折算成标准不确定度后与温度差、伸长量相比得到相对值。最后把这些相对分量平方相加再开方，就得到 α 的相对不确定度；结果按只保留一位有效数字的不确定度来修约，并与公认值比较求相对误差。

=== 体会 ===

这次实验里我最先遇到的意外是「看不见伸长」。温度升了三四摄氏度，千分表的表针只转过很小的一个角度，我盯着表盘看了半天才确认它真的动了。以前做长度测量，米尺上一毫米的分度看得很清楚；这次才体会到，把一个只有零点几毫米的变化测到微米级，靠的不是眼睛更尖，而是仪器把位移转换并放大成了可以读的角度。千分表内部那套齿条齿轮，其实就是一个机械放大器。

装夹这一步让我吃了苦头。第一次装表时我把测杆压得太紧，升温后表针几乎不动，拆下来重装才发现测杆被顶住了；第二次压得太松，读数又跳来跳去。来回试了几次才明白，测杆与棒端之间要「有接触、无压力」：既要保证棒伸长时推得动测杆，又不能让测杆限制棒的伸缩。这个尺度没有刻度可循，只能靠手感和小幅度升温来试。

控温的过程也让我改变了对「等一等」的看法。我原以为温度到了设定值就算平衡了，可屏幕上显示的温度还在缓慢爬升，动态偏差和静态偏差的区别就是这时候看明白的：越过设定值的那一下是超调，来回摆几次之后稳定下来剩下的偏差才是静态偏差。老师说必须等两分钟波动小于 0.1 ℃ 才能读数，我一开始觉得太教条，直到有一次提前读数，前后两组数据的增量明显不成比例，才意识到温度没稳定时读出的 l 是不可靠的。

数据也给了我一个教训。我的第二组温度记错了一位，作图时那个点明显落在直线下方，斜率被拉低了近百分之二。回过头查记录，是抄写时把末位 8 写成了 2。以前做数据处理，遇到偏离的点总想「可能是偶然误差」把它留下；这次我把两种算法都算了一遍，发现去掉那个点以后拟合结果与两点法几乎重合，才确信是抄写错误。数据里没有「大概」，只有对和错。

最后我对这个实验的设计有了新的理解：它把「测一个极小的量」拆成了「测一个较大的温度差」和「测一个被放大的位移」两件事，再用相减的办法把零点、初始压紧量这些说不清的系统项一起消掉。线性拟合又让全部数据都参与进来，比只用首末两点的两点法稳健得多。我想，以后再遇到测不准的量，先别急着找更贵的仪器，先想清楚误差主要来自哪一步，再用「放大」和「差分」这两个最基本的办法去化解。

=== 思考题 ===

1. 分析哪一个量是影响实验结果的主要因素？操作时应注意什么？
（答）主要因素是温度差与伸长量的测量。原长以毫米计，相对误差极小；而 Δt 若有 0.1 ℃ 的偏差，在十几摄氏度的区间里就是约百分之一的相对误差；ΔL 由两次千分表读数相减得到，示值误差、接触压力、支架受热都会掺进去。因此要让棒与千分表一次装好、升温后不再触动，等温度波动小于 0.1 ℃ 再读数，并保持水循环稳定、升温幅度一致。

2. 两根材料相同、粗细、长度不同的金属棒，在同样的温度变化范围内，它们的线膨胀系数是否相同？膨胀量是否相同，为什么？
（答）线膨胀系数只由材料决定，与试样的长短、粗细无关，所以两根棒的线膨胀系数相同；但膨胀量 ΔL = αLΔt 与原长成正比，长的那根膨胀量大，粗细则几乎不影响线膨胀量（横截面积只出现在体膨胀里）。这说明不能拿膨胀量的大小去比较材料的热膨胀特性，必须用与尺寸无关的相对量 α 来比较，这也是引入线膨胀系数的原因。

3. 若实验中加热时间过长，使仪器支架受热膨胀，对实验结果将产生怎样影响？
（答）千分表测的是滑动端相对固定端的位移，其中含着支架自身的变形。若支架与金属棒同向伸长，测得的伸长量偏大，算出的 α 偏大；若支架受热使千分表座与棒端脱离接触，读数会跳变甚至停滞。此外加热过久会让水温与棒温脱节，平衡判据失真，读数不再对应同一温度。所以要控制升温幅度与保温时间，并缩短高温停留时间。
