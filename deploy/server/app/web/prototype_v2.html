先说清楚这个工具做什么

它只做三件事：识别你上传的原始数据记录页、按教材公式计算、按学校模板排版。

报告里的每个测量值都来自你自己拍的那张纸，我们不生成、不修改、也不"补全"任何数字。某处识别错了，在核对页改掉再生成即可。

它是排版与计算辅助，不代替实验，也不对测量数据的真实性负责。提交前请自己再校对一遍。
