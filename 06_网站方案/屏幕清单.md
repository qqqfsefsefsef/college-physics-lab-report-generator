# 屏幕清单 v2（按 m01015 讨论定稿）

> 一句话：**公告 → 首页双通道 → 配置 → 上传+选实验 → 对话式核对 → 生成 → 结果 → 重做/清理**
> 所有屏幕单页应用内切换，不发网络请求（除"测试连接"与生成，原型里都是模拟）。

## 状态机

```
draft ──上传齐──> ready ──点生成──> reviewing ──确认──> generating ──完成──> done
                                        │                                    │
                                        └──改了格子──> reviewing             └──重做──> generating（沿用已核对数据）
任何阶段 ──关页面──> 保留项目（localStorage 只存 project id 与进度标记，不存 key、不存文件内容）
```

## 屏幕表

| # | 屏幕 | 目的 | 输入 | 输出/下一步 | 失败态 |
|---|---|---|---|---|---|
| S0 | 公告（模态） | 说明工具边界、免责 | — | 「我已知晓」→ S1 | 关不掉也不能跳过（无 X 按钮，只有知晓） |
| S1 | 首页 | 分叉两条通道 | 点击卡片 | 自带 API → S2；官方通道 → S3 | 官方通道关闭时卡片置灰标「未开放」，点击只弹提示 |
| S2 | API 配置 | 让用户填自己的模型接入信息 | base_url、模型名、api key | 「测试连接」通过 → S4 | key 错 / 模型无视觉 / 超时 / 限流，分别给不同文案 |
| S3 | 兑换码（未开放） | 预留代付通道 | 兑换码 | 校验通过 → S4 | 未开放 / 码已用 / 码过期 |
| S4 | 上传 + 选实验 + 格式 | 收齐三类素材、确认实验、选输出格式 | 原始数据页（必）、学习通截图（选）、旧作业样本（必）、实验（自动识别可改）、格式（多选） | 「生成」→ S5 | 缺必填项按钮置灰并提示；识别不出实验时退回手选 |
| S5 | 核对（对话式） | **闸门**：逐格确认识别结果 | 左侧表格可改、右侧对话提示 | 「数据确认无误」→ S6 | 冲突/低置信项标黄，必须逐条"知道了"才能继续 |
| S6 | 生成中 | 等待与进度 | — | 自动 → S7 | 中断可重试；失败保留项目与已确认数据（不重花 token） |
| S7 | 结果 | 交付 + 声明 + 出口 | — | 下载 / 重新生成 S8 / 清理 key S9 | 下载失败给直链；未下载就关页面时提醒 |
| S8 | 重新生成 | 收原因，喂优化 | 原因多选 + 备注 | 提交 → 回 S6（沿用已核对数据） | 超过免费次数提示收费（本期关闭） |
| S9 | 清理与隐私 | 闭环 key 与文件 | 勾选确认 | 「完成」→ S1 | — |

## 每屏要点

**S0 公告**：非全屏白底卡片（约 560px），背后 `backdrop-filter: blur(6px)`。三句话，不滚动。链接「数据与结果说明」展开完整版。

**S1 首页**：
- 卡 A「自带 API」——说明：用你自己的模型额度，报告成本你自己可控，key 不留存。
- 卡 B「官方通道」——`FEATURE_OFFICIAL=false` 时显示「未开放 · 联系作者获取兑换码」。
- 底部一行灰字：数据与结果说明（打开 S0 全文版）。

**S2 API 配置**：三个输入 + 一个「测试连接」。测试用一次 16 token 的调用判断三件事：网络通、key 有效、**模型支持图片**。三者任一失败给不同文案（这是最容易被骂的地方）。key 输入框 `type=password` + 显示切换；页面明确写"仅在本次会话内存中使用，关闭页面即失效"。

**S3 兑换码**：一个输入框 + 说明「一次一码，用完即失效」。当前关闭，只显示占位符。

**S4 上传 + 选实验 + 格式**：
- 实验：进页面先自动识别（模拟识别为"用静态拉伸法测金属丝的杨氏弹性模量"），顶部一行"识别为《…》 改？"点击展开下拉（11 套）。
- 三个上传位：原件必填两个（数据页、旧作业），截图可选。
- 格式：PDF（推荐，已勾）、Word、JSON、PNG。一句话推荐，不解释用途。
- 成本预估：约 8k tokens ≈ ¥0.05（BYOK 时显示，官方通道显示"消耗 1 次"）。
- 未填齐时「生成」置灰，鼠标悬停说明缺什么。

**S5 核对**：左侧可编辑表格（表 1 八行），右侧对话气泡逐条报问题。"确认"按钮在把标黄项都点掉后才亮。

**S6 生成**：三段进度（识别 → 计算 → 排版），每段有耗时；可后台继续（原型只显示进度条）。

**S7 结果**：三个数字卡（Y、u(Y)/Y、与公认值偏差）+ 下载按钮 + 声明两行 + 三个出口（重新生成 / 清理 API / 回首页）。

**S8 重新生成**：原因多选（数字识别错 / 文字不喜欢 / 格式不对 / 模板错 / 其他）+ 备注，写明"默认沿用已核对数据，不重新识别"。

**S9 清理**：勾选清单三行——我们的 key 已删 / 平台记录去这里删 / 上传文件 24 小时内删除。给"我已完成"按钮。

## 待定（下一轮讨论）

1. **收费形态**：兑换码（一次性、绑定手机尾号、有效期）vs 二维码支付（微信/支付宝聚合）。前者简单可控、适合熟人；后者要资质与对账。
2. **官方通道的限次**：每码 1 次 / 3 次重做？重做是否折半计费。
3. **记什么做迭代**：只记"实验类型 + 格式选择 + 失败原因 + 用户改过的格子数"，**不记图片、不记学号姓名**（脱敏后再入库）。
4. 官方通道调用的模型选型与降级策略（exp 模型下线怎么办）。
