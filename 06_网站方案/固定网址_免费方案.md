# 给同学用：最便宜的四条路（2026-10 价格）

> 目标：同学打开一个网址就能用，你尽量不花钱。
> 结论：**想马上给人用 → 方案 A（¥0，今天）**；**想要固定网址 → 方案 B（¥10–15/年）**；**不想开自己电脑 → 方案 C/D（¥38/年 起）**。

| 方案 | 总成本 | 网址 | 你的电脑要开着吗 | 多久能用上 |
|---|---|---|---|---|
| **A 临时隧道** | **¥0** | 每次重启都变 | 要 | 10 分钟 |
| **B 域名 + 命名隧道** | **¥10–15 / 年**（只买域名） | 固定 `https://report.你的域名` | 要 | 1–2 小时（DNS 生效要等） |

| **D 香港轻量** | **¥24 / 月** | 固定，可挂域名免备案 | 不要 | 40 分钟 |

## 方案 B：固定网址，一年十来块（推荐）

**思路**：域名挂到 Cloudflare（免费），用「命名隧道」把 `https://report.你的域名` 永久指向你电脑上的服务。分两条路径：`/api/*` 走识别桥，其余走静态页面——所以同学只需一个网址，不用填「连接设置」。

### B1. 买域名（¥10–15/年）

阿里云/腾讯云搜「域名注册」，选 `.top`/`.xyz`/`.icu`（最便宜），买 1 年。**不需要备案**（服务器在你自己电脑上，不在大陆机房）。

### B2. 把域名托管到 Cloudflare（免费，10 分钟）

1. 注册 [cloudflare.com](https://dash.cloudflare.com/sign-up)（邮箱即可）
2. 首页点 **Add a site** → 输入你的域名 → 选 **Free** 套餐
3. Cloudflare 给你两个 NS 地址（形如 `xxx.ns.cloudflare.com`）
4. 回域名注册商 → 域名管理 → **修改 DNS 服务器** → 把两个 NS 填进去
5. 回 Cloudflare 点 **Done, check nameservers**，等 10 分钟–2 小时，状态变成 **Active** 就好了

### B3. 建隧道（命令行，复制粘贴）

```powershell
# 1) 登录（会弹浏览器，选你的域名域名，点授权）
cloudflared tunnel login

# 2) 建一条叫 report 的隧道，记下它打印的 UUID
cloudflared tunnel create report

# 3) 把域名指到这条隧道
cloudflared tunnel route dns report report.你的域名
```

### B4. 写配置文件

在 `C:\Users\lidey\.cloudflared\config.yml` 新建（用记事本，注意 **UTF-8**）：

```yaml
tunnel: 把B3打印的UUID粘这里
credentials-file: C:\Users\lidey\.cloudflared\把UUID粘这里.json

ingress:
  # 识别桥：/api 开头走 8732（页面会自动把接口地址定成 https://域名/api，不用手填）
  - hostname: report.你的域名
    path: /api/*
    service: http://127.0.0.1:8732
  # 其余走静态页面
  - hostname: report.你的域名
    service: http://127.0.0.1:8731
  # 兜底
  - service: http_status:404
```

> `cloudflared` 不会剥掉 `/api` 前缀，识别桥已经做了兼容（`strip_api()`），所以两种反代都能用。

### B5. 启动

一个窗口跑网站：

```powershell
cd "C:\Users\lidey\Desktop\实验报告制作沙盒\06_网站方案"
.\start.cmd -Lan
```

另一个窗口跑隧道：

```powershell
cloudflared tunnel run report
```

### B6. 验收

浏览器打开 `https://report.你的域名/api/health`，看到 `{"ok":true,...}` 就通了；
再打开 `https://report.你的域名/` 就是页面。发给同学即可。

### B7. 开机自启（可选，省得每次手动开两个窗口）

```powershell
cd "C:\Users\lidey\Desktop\实验报告制作沙盒\06_网站方案"
powershell -ExecutionPolicy Bypass -File .\开机自启.ps1
```

它会注册一个「登录时自动运行」的计划任务（网站 + 隧道）。不想要了：

```powershell
powershell -ExecutionPolicy Bypass -File .\开机自启.ps1 -Remove
```

## 方案 C：不想开自己电脑，一年 38 元（国内 IP 直连）

1. 阿里云/腾讯云买**最低配轻量**（活动价 38 元/年 那一档，1 核 1G、峰值带宽 200M）
2. 地域随便选（国内），系统 **Ubuntu 22.04**
3. 控制台**防火墙放行 80**（只用 IP 访问，不用备案；备案只针对域名）
4. 按 `deploy\新手搭建教程.md` §3.4–§3.9 走：ssh → 装 docker → scp 传包 → `.env` 里 `SITE_ADDR=:80` → `docker compose up -d --build`
5. 同学打开 `http://你的IP/`

**注意**：国内机房用**域名**访问必须备案；只用 IP 一般不需要。带宽小（3M 或峰值 200M 共享）→ 上传 3 MB 照片大约 2–5 秒，够用。

> 1. 打开 https://report.你的域名
> 2. 点「我已知晓」
> 3. 首页选「接入自己的 API」，填 key（`sk-` 开头，只在网页内存里，不上传保存），点「测试连接」

## 常见问题

**Q：一定要域名吗？**
A：不用。方案 A 用随机地址、方案 C 用 IP。域名只是让网址好记、能上 HTTPS。

**Q：隧道免费有没有隐患？**
A：Cloudflare 免费隧道不限流量、但**没有 SLA**（偶尔抖动）。给几十个同学用完全够。别用来跑商业流量。

**Q：我电脑睡眠了怎么办？**
A：设置里把睡眠时间调长，或者电源计划改成「永不休眠（插电时）」；不建议禁用屏幕关闭。

**Q：会被 Cloudflare 要求备案吗？**
A：不会。备案是大陆机房的要求，你的服务在自己电脑上。

**Q：同学说打不开 /api/health 不通？**
A：按顺序查：① `start.cmd -Lan` 窗口还开着吗 ② `cloudflared tunnel run` 窗口还开着吗 ③ `http://127.0.0.1:8731` 本机能开吗 ④ `config.yml` 里 UUID/域名有没有写错 ⑤ 隧道和页面是不是同一个域名。
